2. **Team files.** The team is installed by `copilot/install.sh` from the team's own repository. It puts the agents in `.github/agents/`, the commands in `.github/skills/`, the session hook in `.github/hooks/dream-team.json` and everything else in `.github/dream-team/`, and lists what it wrote in `.github/dream-team/.installed`. For each name in `agents[]` verify `.github/agents/<name>.agent.md` exists and its frontmatter `name:` matches; for each in `skills[]` verify `.github/skills/<name>/SKILL.md`. Verify every template path under `templates` exists and `templates.standards` contains `_generic.md`. Verify too that every script the `checks` block names exists under `.github/dream-team/`: `checks.knowledgeIntegrity` and `checks.learningsInbox` each give a path relative to the team root, and a deployment that lost them passes every other test in this skill while `/generate-knowledge` silently cannot verify its own work. Do the same for `updateCheck.script` and `tracking.migration`, and for every `services[]` entry verify its `script` and its `questions` directory exist. Report anything missing by name; a missing file means an incomplete deployment, and the fix is to run `copilot/install.sh` again from a fresh copy of the team's repository, which this skill never does by itself.
