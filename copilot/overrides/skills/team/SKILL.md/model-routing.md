## Model routing

Every subagent call runs on the session model: pass no model on any call; no agent file names one. VS Code and the Copilot CLI name models differently, so a table of model tiers could not be followed the same way in both, and the installed `team-manifest.json` carries no `modelRouting` block. Never choose a model for a call on your own estimate. A user who wants a different model switches the session's model, and the run carries on unchanged.
