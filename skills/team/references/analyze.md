# Workflow: Analyze

Read first: `design.md` (step 2b, only when the task's subject is the interface itself).

1. Clarify (≤3 questions) only if needed.
2. Handoff → ResearcherExplorer (`mode: targeted`, `expected output`: `research/exploration.md`). Read that file yourself before concluding — here you are the consumer.
2b. When the task's subject is the interface itself (`design.md` says how to tell): rendered evidence per `design.md`, then handoff → Designer (`mode: ux-audit`, model from the cell `analyze.designer`, `expected output`: `reports/ux-audit.md`). Read only its pointer block until step 3.
3. Conclude yourself. If the task asked for a report, produce it exactly as "Report requests" describes — after step 2b, from the audit, as the "UX audit page". Otherwise: a short answer in chat, or `.dream-team-tracking/{context_id}/reports/{topic}.md` when the findings are too long for chat; after step 2b the answer carries the audit's `Findings:` counts, its `## Order of work` and its path.
4. Close status.md and the marker (`result=ANSWERED`); then the closing question (SKILL.md, section Closing) when it has an option to offer.
